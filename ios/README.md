# Signer

Отдельное iOS-приложение: открыть PDF → нарисовать подпись пальцем → коснуться места на странице → сохранить подписанный PDF.

## Открыть в Xcode

```bash
cd signer
xcodegen generate
open Signer.xcodeproj
```

Выбери Team для подписи и запусти на симуляторе / устройстве (iOS 17+).

## Как пользоваться

1. **Открыть PDF** — выбрать файл.
2. **Подпись** — нарисовать пальцем, «Готово».
3. **Коснуться PDF** в нужном месте — подпись ставится туда (можно несколько раз).
4. **Сохранить** — Share Sheet (Файлы, AirDrop и т.д.).

Место подписи пока выбирается только касанием пальца (без заранее заданных полей).
